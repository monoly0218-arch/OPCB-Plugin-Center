# 插件中心重设计 · 2026-11-14

## 0.2.1 图标对齐修订

按本人后续要求，复用7项插件包内icon.png与选题灵感页面SVG，校验内容与Studio当前运行产物一致；不再为已有图标的插件另配Fluent对象。来源路径、原始revision及图像摘要在 `src/plugin-center/assets/NATIVE_ICONS.json`。插件中心新增icon.png，并用完全相同的拼图PNG注册公开pages.icon，使管理页、导航、目录图标一致。官方最新与设备再次核对均为Buzz 1.0.2，使用同一公开API和既有权限。

其余7项尚无独立原生图标（Grok、Muse、号池、热点工厂、HTML阅读器、知识库管理、商业化计划与报告），暂保留用途图标，不声称已与不存在的原图对齐。没有修改这些插件。目录支持可选内嵌icon，后续插件发布可同步提供图标；不新增远程图标请求或账号配置读取。0.2.0包保留，新增0.2.1候选、独立固定来源审核；不自动合并或安装。

## 方向

- 产品：帮助OPCB成员找到插件、核对目录版本并发起原生审核。
- 性格：温和、明确、有辨识度。
- 场景：日常工作工具架；沿用共享OPCB v3的圆体、黑色工作区和16px内容圆角。
- 重点：每个插件的立体用途图标与足够大的名称、版本；其余界面保持安静。
- 识别细节：同一插件各版本保持同一用途图标，日期版与rc版忠实展示来源。

## 原界面与改动

原版已有有效的搜索、分类、固定来源审核、失败保留与历史版本功能，继续保留。原版采用普通系统字体和满屏摘要、依赖说明、仓库提交提示，图标缺失，版本混在14px辅助信息中。此次重做界面而不扩大业务权限：默认只保留名称、图标、版本、状态和操作；详细依赖放在18px详情页。最小可见字号16px，版本19px，名称21px，窄屏名称20px。

按间距、颜色、图标、文案、字体、布局、细节、视觉、动效依次校验。原Skill中的默认单色线图建议不覆盖用户明确指定的最新v3立体对象风格。共享库本身不修改。

## 兼容与边界
