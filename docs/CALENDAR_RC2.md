# 日历 0.1.0-rc.2

- 月历以月份为主，控制区收紧。按类别区分日程，同一天的完整安排可在右侧查看。窄屏用每格日程数保持月历可读。
- 周历从周一开始。全天安排放在上方，定时事件按小时定位，重叠事件并列，跨天事件显示当天部分。
- 桌面端日历与详情、编辑并排，分别滚动；窄屏将日程面板移到网格下方。点击一项安排可直接聚焦详情。
- 沿用原公司看板人员组件、原来源权限及 Canvas 保存流程。日程仍限请假、出差、线上会议、线下会议和里程碑。
- 参考本机 Woday 1.4.3 的月历信息层级和右侧详情布局。插件采用 OPCB 的配色、状态和五类业务规则。

核对官方稳定 Buzz v1.0.5、本机 1.0.6-preview.1、插件 API 1。隔离验证覆盖月／周、重叠时间、深浅色、390／768／1024／1440／1680 宽度、键盘返回、人员筛选及新增／编辑／二次确认删除和模拟冲突保留草稿。真实共享保存和跨设备同步待原生安装后验收。原生更新由本人通过审核卡确认。界面方法与身份资源署名见插件内说明。
