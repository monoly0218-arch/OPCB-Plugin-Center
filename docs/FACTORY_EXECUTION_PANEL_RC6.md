# 内容工厂 rc.6 制作面板

1. 可收起面板依次显示一个提示词、角色、产品和视频历史。提示词默认最新，可选择以前的版本。原生执行会话持续挂载，折叠面板增加可用会话空间。
2. 本人点击开始执行后，输入与图库图片形成不可变版本快照，发送到该素材专属 Solo，附真实图片及准确版本编号，提及本人选择的执行 Agent。原生 outbox 和持久发送编号支持回执核对，重复点击复用原指令。
3. Agent 实际开工后调用 start，交付真实附件后调用 deliver，再通过 update_prompt 保存完整修订提示词及其消息证据。实际使用提示词和修订提示词分别留存。替换输入后再次执行自动生成新版本。
4. 图库存于本人私人 Solo 的 Canvas，各素材复用。一个条目可保存多张图片；跨身份清除读取状态，归档冲突可恢复成功上传的文件。业务图片与来源只保留在本人资料中。
5. 版本状态沿用灰／蓝／红／绿。绿色由本人页面验收产生。验收工程 ZIP 包含原始输入、真实图片、成片及可选 NEXT_PROMPT.md。Higgsfield号池待接入。

官方参考 v1.0.5，macOS 本机 1.0.5-preview.2，API1。现有宿主权限不变。完整验证入口 npm run ci；页面验证使用真实源码和隔离的原生 API / 业务样例。实际生成、实体 iPad 仍待独立验收。
