# 日历 0.1.0-rc.1

新插件ID opcb.calendar，名称「日历」。用户请求来源：本地开发记录保存原Buzz消息 bd81909cc77f9a3ae7f5c71f4c4ade1a53b98699a5808e3d9c329cb67a24200a。

1. 日历视图：月、七天、今天、按五类/人员筛选、查看详情、登记、修改和删除；支持全天、具体时间与跨天。只允许请假、出差、线上会议、线下会议和里程碑，任务排期不自动进入。
2. 人员卡片：复用公司看板rc.17原黑色照片卡与状态/当前事情/今日进度口径，读取同源人员与任务。点击卡片查看该人员日程，不增加第三个功能页。
3. 数据：原授权工作来源Canvas的独立日程区，共享给该来源的现有成员；只改本插件区。当前来源成员可登记，仅登记人或来源创建者可改删；所有保存以最新head和原生CAS确认。请假不表示审批。
4. Agent：opcb_calendar工具先read，再按本人原指令和最新baselineRevision写入。只允许本人及调用Agent均获准读取的当前会话，不自动执行普通任务。
5. 安装：固定分发分支 distribution/calendar-rc1-20261118；在REGISTRY中绑定完整提交。本人在Buzz原生卡片审核后才安装。目录变更以草稿PR交付，尚未合并正式发布目录；不更改原17项基线或旧团队日历连接。
