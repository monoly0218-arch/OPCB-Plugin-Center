## 界面方向

产品：内容生产与品牌素材的日常工作台。性格：克制、清晰、以素材为先。场景：团队选片与素材管理。重点：真实素材、阶段与版本。识别：保留认可的立体导航图标。

## 功能与边界

内容工厂：

- 原生阶段与部署版一致：approved 进入高赞排行，done 进入待审核，收集仅含 pending + ready。
- 待我评审/全部、单一高赞排行、收集者筛选与创作者搜索；排行票数相同时按原站创建时间排序。
- 展示原站返回的历史成片版本；只有已有签名媒体地址才播放。历史版本没有授权地址时提示进入完整工厂，不用当前成片冒充。
- 六个阶段与收集、下载队列、已收起固定可见；原生支持评审、撤销、稍后看、确认、开始制作、成片审核、退改和评论草稿。写前核对版本，写后回读不确定则锁定后续修改。上传、滑卡评审、批量下载与未读管理仍在实时「完整工厂」中使用。新增写入仅模拟服务验证，不代表真实业务验收。
- 保留已有原生助手与标题/备注建议。进入网页操作会清空原生选中项和建议，拒绝基于旧选中项的 Agent 调用。

资产库：

- 默认直接进入原站实时工作区，不展示空白快照或本机样本数量；保留原站完整操作、重新载入。
- 保留现有私人助手。网页中选择的素材不会自动传给助手，本次未宣称完成原生资产 API 或自动选中联动。
- 原站上传/删除/发布等操作仍由用户主动执行。重新载入前先保存未提交内容。
- 不支持内嵌网站的设备显示明确说明和原站链接，不渲染空白浏览器。
