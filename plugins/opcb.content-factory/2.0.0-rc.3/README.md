## 实机差异与执行会话修复

使用与任务中心一致的完整原生 Workspace：选择可访问会话、新建／续接 Solo、可调宽度分栏、原生输入框与附件。选择或创建会话不发送消息、不自动开工。会话绑定仅记在本机当前身份及社区，跨设备同步未接入。当前素材可由本人点按钮填入草稿后发送；素材工具仍仅向已关联的本人和单 Agent 私人 Solo 提供读取及建议。

字体使用 FontFace 字节注册，避免桌面 CSP 拒绝 data URL 字体。

视频使用原生 video，移除嵌入浏览器地址栏。新增 host.processes 的 Python 3 本机只读媒体流：仅转发当前已授权的 staging.paolab.cn/ins/media 或 results 签名地址，绑定127.0.0.1、随机单次路径，拒绝重定向，不复制Cookie、不落盘，不提供任意URL代理。换素材、关闭页面或替换插件后结束进程。Python 3 不可用时明确提示并可进入原站。
