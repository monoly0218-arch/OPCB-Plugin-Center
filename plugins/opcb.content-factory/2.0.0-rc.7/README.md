# 内容工厂 2.0.0-rc.7

制作设置沿用 OPCB Mobile Design R9 的连续圆角、角色／产品切换和主按钮。宽屏以偏3:4独立面板与原生Solo并排；平板、窄屏上下布局，均可向上收起、向下展开。角色与产品以3:4图卡展示，完整保留原图比例。默认显示最新提示词，可选择历史版本；角色库与产品库按图片勾选，下方查看视频历史。执行会话持续使用同一原生 Workspace，收起设置或切换版本会保留原生草稿。

点击「开始执行」保存本轮输入快照，将提示词与全部勾选图片作为本人消息及原生附件发送到该素材专属 Solo，并明确提及所选 Agent。首次选择素材会建立或复用命名 Solo；首次执行可通过原生成员接口加入本人选定的 Agent。一个素材保持一个私人 Solo 和一个执行 Agent。指令进入发送队列显示蓝色，实际开工、交付及失败由 Agent 根据真实回执更新。重复点击核对同一个发送编号；发送结果不明时保留原生发送记录，不另发新指令。

执行完成后 Agent 使用 update_prompt 保存完整修订提示词，实际执行提示词仍在本版档案中。本人替换图片、调整提示词后再次点击开始执行，自动建立下一版并封存旧版输入、结果及验收；可查看各版输入档案、比较物料和提示词。只有本人明确验收才显示绿色，验收工程 ZIP 保留真实物料和 PROMPT.md，并在有修订提示词时增加 NEXT_PROMPT.md。

角色／产品库保存到本人私人 Solo 的 Canvas，供各素材复用；图片随执行版本保存独立快照。角色与产品均可在图卡「改名」中手动修改名称，保存时核对图库revision，过期或冲突不覆盖。名称只更新图库，已执行版本保留当时名称与真实原图。可为条目命名、上传一组角色或产品图片，上传后发生归档冲突可恢复原文件。原图和私人来源属于业务资料，由本人账号读取，未放入公共插件包。已有 rc.5 制作记录及图片保留，原图尚未归入图库的以保留条目显示。

插件 ID opcb.content-factory，Buzz API1。官方参考 block/buzz-app v1.0.5，本机 macOS / Buzz 1.0.5-preview.2。继续使用现有 Solo、Canvas、messages.send、memberAdditions、agentChoices、附件和 Workspace 能力，宿主权限与 rc.5 一致。Higgsfield号池尚待接入，实际供应商执行依赖对应 Agent 已具备的工具和有效授权。

构建 npm run build:factory，完整检查 npm run ci。隔离浏览器验证与实际设备、供应商生成验收分别记录。安装通过 Buzz 原生更新审核卡，由本人最终确认。
