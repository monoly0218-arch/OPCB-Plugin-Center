# 内容工厂 2.0.0-rc.5

制作中页面改为「素材列表＋执行规划」的圆角工作区。点击素材才建立、命名并复用本人专属私人 Solo；右侧直接使用 Buzz 原生完整会话，切换制作版本仍沿用同一 Solo 和草稿。打开页面或选择素材不会发送指令、自动开工或调用生成供应商。

左侧状态从同一 Solo 的 Canvas 制作记录实时读取：执行中／待验收为蓝色，本人在页面明确验收后为绿色，生成失败为红色；未开始为灰色。真实生成需在原生输入框向选定 Agent 下达明确要求，Agent 使用 opcb_factory_execution 核对指令及版本回执后写回状态。记录成片只进入待验收，Agent 没有验收操作。

每个制作版本分别保存时间、规划、提示词、参考图片、产品图、人物图、成片与失败原因。新建下一版复制输入物料、清空结果和验收；旧版封存并可查看、比较。新版草稿可独立增删物料，旧版文件不删除。只显示实际存在的版本，不填造三版历史；原工厂已有视频版本保留在其他原有详情和原站，未提供的历史提示词不冒充已归档。

已验收版本可打包为标准 ZIP，包含 PROMPT.md、PLAN.md、MANIFEST.json 和真实物料／成片字节。按当前身份读取并逐个校验 SHA256 与文件大小，缺失或不符则不生成不完整包。单文件最大64MB，工程物料合计最大128MB。工程上传回同一私人 Solo，下载后可由本人交接；不自动分享给其他人。

Canvas 保存使用原生冲突检查与保存后回读；上传成功而归档冲突时保留待归档文件，可重新归档而不重复上传。跨账号／社区和撤权后停止新读写。Higgsfield号池显示「待接入」，本版本没有认领、登录、付费或实际生成能力，等号池接口完成后再接入。

保留 rc.4 的本人角色映射、工厂其他阶段与原站入口、媒体比例适配及3dicons统一图标。ID `opcb.content-factory`，API1，权限与rc.4一致：现有 staging.paolab.cn 网络及 factory-media Python 媒体进程。服务端角色绑定的原边界见 docs/FACTORY_ASSETS_ROLE_BINDING.md。

官方参考 block/buzz-app v1.0.5；验证设备 macOS / Buzz 1.0.5-preview.2。完整检查 `npm run ci`，构建 `npm run build:factory`。隔离页面验证使用真实插件源码与模拟原生会话／业务数据；不代表真实供应商生成或实体iPad验收。安装仍须本人通过原生更新审核卡确认，安装后再回读 revision、active 和错误。
