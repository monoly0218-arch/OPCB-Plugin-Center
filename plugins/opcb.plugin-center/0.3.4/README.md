在「团队协作」中加入已安装的团队日历入口。点击「打开日历」直接打开 opcb.team-calendar/main，继续使用本人现有云端连接。只有宿主确认该插件已安装时显示入口；未启用或导航失败会提示检查，不宣称已打开。

本次只更新插件中心；日历程序、数据库、账号与设备凭据保持原安装。未安装日历的成员仍使用独立日历安装包，在本人电脑完成邀请登记及 Buzz 原生审核。公开目录仅记录入口元数据，不包含私人日历数据或设备连接。

目录分类显示「团队协作」，兼容既有工作协作分类键。保留0.3.3的3dicons V1图标、贡献者、固定版本安装卡、GitHub请求标识及布局。宿主权限仍只有 api.github.com。最低契约API1，官方参考与原目录基线Buzz1.0.2；本机实际能力由plugin_status核对。桌面与移动端业务验收分别记录。

构建：node scripts/build_plugin_center.mjs。完整验证：npm run ci。通过固定提交的Buzz原生审核更新；发卡、安装和人工业务验收分别记录。原业务和图标许可随本包保留。
