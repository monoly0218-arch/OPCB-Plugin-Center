# OPCB 插件中心 0.1.0

Buzz API v1 原生插件。搜索和分类浏览本仓库目录，查看依赖与本机安装状态，点击「审阅安装」或「查看 / 更新」进入 Buzz 宿主审核。

目录来自本仓库 `REGISTRY.json`。先读取 main 的完整提交，再按同一提交读取目录；安装源固定到目录中独立分发分支的提交。仓库变动导致版本不匹配时拒绝安装，需要刷新。既有 1.3 号池收在历史版本中，默认展示 1.4；两者插件 ID 相同，不能并行安装。

## 能力与边界

- 仅声明 `https://api.github.com` 网络访问，读取公开目录，不使用 GitHub 令牌或网站 Cookie。
- 安装由可选 `pluginInstaller` 能力完成，用户须在宿主中确认。页面不会静默安装、批量更新或扩大权限。
- 「已安装」只代表同 ID 已存在，不能据此判定版本相同、插件启用或业务依赖可用；具体版本在审核中核对。
- 当前宿主缺少安装状态能力时显示「状态待核」；缺少安装能力时保留源码和下载入口，并说明需要更新宿主。
- 首次打开页面和手动刷新时读取目录，不后台轮询。刷新失败保留上次目录，停用安装动作，防止用失效目录继续操作。

## 安装

由 Buzz Agent 从此仓库的单插件分发分支 `distribution/plugin-center-0.1.0`、路径 `.` 发起安装审核卡，并固定该分支精确提交。由用户最后审核安装；不手动修改安装注册表。

## 验证

完整仓库检查为 `npm run ci`：全部 Node 测试、JS 语法、分发目录、ZIP 和校验值。测试覆盖固定版本、错误目录、刷新失败、重复点击、取消/失败审核、宿主能力缺失和停用清理。浏览器预览使用真实 React 与宿主替身，不等于真实 Buzz 安装验收；CI 状态以 GitHub 当前 head 回执为准。

## 界面方向与署名

面向 OPCB 成员的共用工具目录。字体、语义色、深浅色和控件沿用 Buzz；分类导航和安装状态帮助挑选，依赖说明按需展开。无装饰性指标或虚构用户数据。
