# OPCB 平台商业化计划与报告 · 2.0.0-rc.11

打开时先显示可操作界面。有授权的最近一次报告直接从本机读取，首次无缓存时在后台读取一次。缓存保存在 Buzz 本机存储，按身份和社区隔离。点击「更新数据」拉取最新内容，查看手机版时才加载原稿。中文使用系统字体，缩小首屏代码。

图谱连线使用自动选边、矩形避障的圆角直角路由，计入折弯、交叉与共线代价。拖动节点后重新路由，保留用户位置；节点重叠没有合法出口时暂不画穿框线。参考 React Flow 路由及 yFiles EdgeRouter 的设计原则，独立实现，不引入商业图库。

缩放工具缩为32px高图标条，放在画布内容上方。图谱与详情保留可调左右分屏，分隔线默认隐藏，悬停或键盘聚焦时提示拖动。模块按可用高度伸展，参考／成果保持原比例。详情关闭统一一个图标，取消重复返回按钮。

评论平时仅一个角标，点击打开评论弹窗；保留草稿、原生Buzz当前身份、头像、频道角色及消息发送。网页版仅为审阅访客，访客记录不迁移成本人消息。

素材通过本人授权的审阅JSON和精确Buzz消息附件关联，复用网页已审阅参考视频与静态海报；参考不冒称成片。R8手机稿绑定沿用，来源权限、原生媒体URL、身份切换保护不变。分发包不含私人数据。

opcb_commercial_review_source支持本人授权的精确清理清单：仅从此商业化工作区移除指定旧任务、内容排期和旧目标计划，保留未排期的成品标题；正式共享Canvas、其他插件及新任务ID不受影响。已登记实绩保留。未交付成片、真实发布／领取及内嵌Solo仍待业务接入。

兼容：官方Buzz API v1。验证平台：macOS、本地候选浏览器与API测试；更新须原生审核卡及本人最终确认，不代表Android/iOS真机验收。
