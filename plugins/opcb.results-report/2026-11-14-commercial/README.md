# OPCB 平台商业化计划与报告

沿用插件ID `opcb.results-report`，保留原品牌模板库和手机截图，新增上线日期15/17方案、上线后4天每日分工与甘特图、内容引流、费用与免费次数情景、真实转化数据和任务证据。默认空白；团队计划通过本人授权的私人JSON导入，不随公开包发布。

## 使用与数据

1. 在计划区导入团队计划JSON；切换15/17只重排日期，不等于日期确认、上线或任务执行。按日/人员查看，甘特图可展开。任务状态和交付链接手动维护。
2. 每次修改后点“保存计划与进度”；有未保存提示，导出计划JSON可先保留未保存内容。重新打开读取已保存记录。数据按本机当前身份和社区隔离，不自动同步群聊或其他设备。
3. 费用默认是估算；可调单次成本、免费1/2次、人数、付费转化假设和媒体预算，计算补贴、达到付费目标所需人数和成本。界面不会批准或花费预算。真实数据留空，未知不同于0；累计人数不按每日简单求和。
4. “真实数据与复盘”填写同一窗口的累计去重值、统计截止与证据。费用中免费补贴是生成实付子集，总收支不再次扣除。无付费不计算CAC；不完整账目不称净利润。
5. 原模板库保持独立导入/导出。计划`commercial-plan`与原`library`均使用原`brand-library`集合、原type及version，不搬动、覆盖或公开旧样片。升级后原5模板和26屏继续保留；新包不含媒体。

## 兼容与验证

参考官方当前稳定v1.0.2及已发布v1.0.3-preview.1；Studio实际1.0.1。只使用API v1的react/pages/relay/artifactStorage，无新增host权限。原生更新须本人在审核卡最终确认，不自动升级宿主。验证：完整npm run ci、独立存储/导入/日期与计算测试、Ego浏览器交互和390px布局；具体本次结果以交付回执为准。安装后的真实持久化与业务验收另核，演示不冒充宿主测试。
