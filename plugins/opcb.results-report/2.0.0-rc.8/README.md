# OPCB 平台商业化计划与报告 · 2.0.0-rc.8

增长图谱改为可平移、缩放、适应窗口的画布，保留12类需求、10篇内容及关联线；选择节点在同页展开详情，返回时保留画布位置。桌面模板工作区以参考、成果、评论三列显示；窄屏顺序排列。评论常驻圆角聊天区，复用于发布内容、任务、账号及其他模块；发送使用当前Buzz身份、头像、频道角色及原生消息，未知投递先核对，避免重复发送。

保留ID `opcb.results-report`、`report`页面、Dock入口、3dicons V1图标、原任务来源与brand-library集合。标题、文案、标签逐字段保存，冲突保留草稿。删除解释性小字、重复状态行及手机稿10个快捷入口；手机流程保留交互／平铺选择，标题为一行。

手机HTML通过本人原执行消息关联，使用当前身份核对消息及附件权限，私有源描述保存在当前用户的Artifact偏好内；公包不内嵌私人HTML、图片、源消息或客户素材。`opcb_commercial_mobile_source`可读取／关联来源，写入需本会话本人更新指令、当前revision和可读原附件。关联读取是本人来源副本，不改OPCB Mobile的绑定。安装后由执行Agent接续关联已确认手机稿；尚未关联时显示缺失状态。嵌入手机HTML使用无同源权限的sandbox，关闭/换账号清理对象URL。

原生任务继续读取当前可访问的共享来源；网页版为审阅快照。成片、真实发布/领取、自动数据采集、内嵌执行Solo仍按真实接入情况保留缺口。原始业务数据、标题草稿和旧版不会随安装主动覆盖。网页批注历史保留在服务器，原生评论走Buzz，不把匿名网页访客冒认为Buzz用户。

本轮参考官方Buzz v1.0.5、Studio实际1.0.5-preview.2、API v1。所用能力react/pages/relay/artifactStorage/agents，未新增host命令或网络授权、未修改宿主。完整npm run ci和EGO主题／宽度／交互检查；安装审核、真实账号发送和手机真机验收分开。固定来源更新卡需本人最终确认。
