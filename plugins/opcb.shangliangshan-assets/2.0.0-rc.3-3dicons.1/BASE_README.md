# 上粮山资产库 2.0.0-rc.3

默认使用原生资产工作区：已确认的粗圆体字号、灵动岛、EGO式分组侧栏、实时资产网格、分类、标签、权限与详情；不再以整页原站替代审阅的新界面。保留任务中心标准的完整原生执行会话与可调宽度分栏。

## 数据与身份

新增Python3 `asset-session`进程权限。用户在原生页面主动选择原站成员后，进程通过原站已有 `/assets/login` 建立全新的内存 CookieJar，沿用原站成员权限；不读取或复制 EGO、Buzz 内嵌浏览器或其他身份的 Cookie，不落盘、不内嵌私人素材。原站的成员署名机制本身不验证真实本人，与 Buzz 身份分别管理。账号或社区切换、插件停用和更新会关闭此会话。

只读接口为原站已有资产数据、平台文案和当前允许文件。缩略图以有大小上限的图片数据返回，视频通过随机本机127.0.0.1路径流式读取；拒绝任意URL、跳转、跨来源或未出现在当前文件表的资源。图片缓存按当前身份限制数量和内存。

## 功能边界

支持全部／最近／本人／待分类／回收站、目录与细分类、搜索筛选、分页、三种布局、图集、真实版本、平台文案复制、人工发布记录，以及标签／成员权限读取页。视频按原始比例及详情栏可用空间适配。未提供的版本和队列不补造示例。

上传、采集、编辑、批量整理和下载、改权限、文案写入及发布登记继续进入明确标记的原站操作入口；切回后刷新真实数据。原站会话独立，首次进入仍需本人选择成员。PDF原件在原站打开。执行会话选择／新建不自动发送消息、建任务或开工；当前资产可由本人点按钮填入草稿。

## 验证与安装

源码 `src/shangliangshan-assets`；本包附可审核的 `ASSET_SESSION.py`，实际执行同样的内嵌源。官方及本机 Buzz1.0.2/APIv1，macOS需要Python3；其他平台不声明通过。构建 `npm run build:factory-assets`；完整检查 `npm run ci`。安装使用REGISTRY固定来源原生审核卡，用户确认后另做实机验收，不以测试通过代替安装或业务通过。
