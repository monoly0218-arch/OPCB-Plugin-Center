# 公司看板 · 2.0.0-rc.13

与任务中心使用同一工作进度群Canvas和现行 `src/tasks/live-model.mjs` 解析器，沿用任务ID、轮次、日期、当前交付及验收事实。新版补齐Agent任务生命周期；不是另一套任务账。

## 查看与追溯

- 总览显示全部事项、进行中、待验收、受阻、已完成和未登记；点击数字进入对应事项。
- 人员视图按明确姓名和别名识别协作参与者，区分潘涛与潘涛 Studio。协作事项可同时出现在多人名下，人员数不能相加充当独立任务总数。
- 项目按来源中的项目/阶段分组，不臆造业务项目映射。保留任务搜索、状态/日期筛选、日历、状态看板、来源正文、主题及字号设置。
- 点事项查看同一原任务，打开当前版本交付、执行会话及来源；修改后旧交付不再显示。移除任务退出列表与统计，恢复保留原ID。
- 旧完工勾选只算待验收，只有当前任务中的本人确认结果进入已完成。受阻可能是进行中任务附带的真实原因，汇总与进行中分开计数。

## 同步与权限

来源为 `buzz://channel/7dc199bc-755b-47bb-8f71-fe311b1f1ab1`。可见页每30秒读取，来源实时信号、回到前台及「手动更新」共用串行读取链；关闭页面清理计时器与订阅。账号/社区切换、撤权、缓存成员信息及读取错误不继续展示旧任务。

看板是汇总与追溯入口，不提供另一路旧执行记录编辑表单；任务执行和验收继续在任务中心原流程操作。保留原私人Solo助手及 `opcb_company_board_task` 只读/定位工具，关联与身份边界不放宽，移除任务不能经工具重新定位。不新增Agent执行工具、宿主权限、自动执行或自动验收。
