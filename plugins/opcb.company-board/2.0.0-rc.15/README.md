# 公司看板 · 2.0.0-rc.15

人员视觉按潘涛 2026-11-15 已认可的双人 Demo 统一应用到全部当前基线参与者：黑色圆角卡、大幅资料照片、圆形头像、姓名和本人状态、当前事情、唯一一条 20px 今日进度条。移除姓名胶囊、项目行和底部多重计数；点击保留原个人任务分组。此版本不重新设计项目页。

## 数据与范围

- 人员名单继续由当前共享工作基线及其参与关系生成，不硬编码人员数量或头像。原生 session.profiles 的 picture 经 session.media 显示；姓名须在当前来源成员中唯一对应。复合别名中的重名短别名不覆盖唯一的完整姓名；多个不同唯一身份仍保持未知。
- 个人状态仅显示本人有效发布的原文。未设置、过期、重名或无对应身份显示「状态未同步」，不推断考勤或工作位置。
- 当前事情来自真实进行中/受阻任务；没有有效回执显示「当前事情未同步」，不把职责分工作为实际开工。
- 今日按北京时间日期筛选已安排的执行任务，保留原本的“已验收完成 / 总数”口径；职责、其他日期、无日期与移除任务不计入今日分母。未登记执行状态、无今日任务时百分比显示「—」，空轨道表示未同步，不能解释成 0%。待验收不算已完成。每人只有一条进度条。
- 照片缺失或加载失败使用姓名首字占位；不会生成或替换他人的头像。源码、分发与安装包不包含真实员工图片、名单快照、聊天资料或演示百分比。
- 项目、阶段、任务、验收、同源自动刷新和权限边界沿用 rc.14。保留插件 ID、main 页面与当前已安装的 3D 图标，不改其他插件。

## 兼容与验证

本轮核对：官方 block/buzz-app 稳定版 v1.0.2，Studio 实际 1.0.2，API v1。使用现有 session.profiles、session.statuses、session.media、React 与 Canvas 读取，不新增 host 权限，不重建或升级宿主。

构建：node scripts/build_company_board.mjs。完整检查：npm run ci。打包：python3 scripts/package_release.py。浏览器检查为 Ego 的隔离只读预览；原生加载和 Android/iOS 实机验收需用户完成审核更新后进行，隔离检查不等于已安装。

安装通过正式 OPCB 插件中心仓库的固定分发提交、Buzz 原生审核卡完成。候选发布与本地检查通过不等于已更新设备。
