# 公司看板 · 2.0.0-rc.14

## 项目与人员

默认入口是业务项目。根据潘涛本轮明确说明，共享来源「OPCB 平台商业化计划与报告」中的原分工/执行计划归入「OPCB 平台商业化」；上线前、上线D0、商业化D1等保留为项目内执行阶段。点击项目查看原任务、阶段、负责人、状态和当前交付。

这层显示映射不修改原Canvas、任务ID、原project字段、状态、日期或负责人。新建任务有明确业务项目名称时保留其名称；来源不明的旧计划显示「未归属项目」，不按标题猜测。跨阶段任务仍是同一个任务，可按原阶段筛选，不增加项目或任务总数。

「项目视图／人员视图」放在内容顶部；人员页一位参与者一张状态卡。卡片展示本人状态、当前进行中/受阻任务、任务完成数、待验收和未登记数；点击按业务项目查看该人的原任务。明确的「潘涛／小跑」协作同时归到两位已知参与者，「小跑／夏明升」原有别名保持同一人。多人协作可出现在多个参与者卡片中，不将参与次数相加当作独立任务总数。职责分工不进入个人任务完成率分母；无执行回执显示待回执。

## 原生状态与导航

导航、字体、面板、间距与图标复用当前任务中心设计系统及reference样式。保留搜索、日历、状态看板、来源、字号/主题和原私人助手。

可选读取官方APIv1 `session.profiles` 和 `session.statuses`：仅对当前共享来源成员，按原分工中的明确姓名/别名唯一对应身份；读取本人发布的状态原文和更新时间。例如本人设「在公司」后显示原文与建筑图标。无记录、已过期、身份重名/未对应或接口不可用显示未同步。任务活动不用于推断工作位置。Agent按原生身份标记区分；不抓取定位、考勤或代改任何人的状态。

状态随原生订阅变化，手动更新也请求原生状态刷新；关闭页面、切账号/社区或撤权后释放订阅并清理显示。状态只作为本人填写的当前说明，没有考勤服务接入或考勤准确性声明。

## 任务同源与交付

继续共用 `src/tasks/live-model.mjs` 任务解析器及原Canvas。新增、开工、交付、修改、改期、移除/恢复、本人验收等事实保持同源；旧完工勾选不算验收。可见页30秒、实时信号、回前台和手动更新共用串行读取入口。任务写入与验收继续走任务中心，不另开旧记录写入口。

保留ID `opcb.company-board`、页面main、已认可图标及host权限。2026-11-14再核官方稳定/Studio均Buzz1.0.2、APIv1；不升级宿主，不更新其他插件。桌面/隔离浏览器通过不等于Android/iOS实机通过。

源码 `src/tasks/company-*`，构建 `node scripts/build_company_board.mjs`，完整检查 `npm run ci`，打包 `python3 scripts/package_release.py`。正式插件中心固定reviewSource见REGISTRY/CANDIDATES。候选发布不等于安装；用户在原生审核卡最终确认。
