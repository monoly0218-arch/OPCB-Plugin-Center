# 聊天产物 2.0：知识库接入候选

版本 **2.0.0-rc.7**，ID `opcb.chat-artifacts`，官方 Buzz 插件 API v1。维护、分发与下载唯一入口为 OPCB-Plugin-Center。

在当前聊天右侧圆角侧栏查看文件、链接、本人／Agent 爱心认可和 V1/V2/V3 版本。保留 rc.5 的共享 OPCB v3 内嵌圆体、Nunito 数字字体、16px 圆角和原生侧栏位置；不修改宿主界面。

## 本次接入

1. 每张版本卡可点击「收入知识库」，保存当前具体版本的原文件、来源消息与版本关系。收藏和入库分别标记，不自动上传已有收藏。
2. 原附件通过宿主有权读取的媒体入口读取，最多32 MiB，分块上传并校验 SHA256；普通网址按链接收录。禁止把 URL 引用冒充原文件保存。
3. 服务器完成保存后再次读取同一条目，核对身份、来源、大小和哈希，才写入「已入库 · 原文件／链接」。上传超时或回执不匹配不显示成功；标记保存失败会明确告知知识库已保存、聊天标记待核对。
4. Agent 使用 `opcb_artifact_archive`，传查询返回的产物 `id` 和 `expected_revision`；人和Agent均保存到所属个人空间。服务记录实际原生绑定操作者，Agent 不冒充本人审核。
5. 知识库阅读候选增加「收藏与产物」入口、类型筛选、原文件读取与下载；集团全部资料的类型筛选也能找到已入库媒体。入库不会自动归属某团队或扩大分享。

## 依赖、身份和权限

需要知识服务启用本分支 `services/knowledge` 的 `collect` 扩展及 `--collection-root`，并有 `collection` 知识源权限；原只读设备绑定仍只能读取。贡献身份单独绑定，按当前个人／Agent公钥隔离，不需要密码；绑定只发布公钥与随机挑战。Agent 继承所属个人库权限，不继承管理权限。

新增的唯一主机授予为 `https://shangliangshan.paolab.cn` HTTPS 请求；没有进程、命令、通用文件系统权限。原文件经 Buzz 自身媒体入口读取。原生更新卡需要本人审阅新增网络权限。

聊天索引、爱心与归组继续保存在本机；入库文件保存在服务器的所属个人空间，不承诺本机标记跨设备同步。服务器每次请求核对权限；停用、撤权拒绝后续访问。新安装不会自动上传历史收藏。

## 现有能力与边界

累计加载历史，重开先读取本机索引，再同步新增／编辑／删除。搜索覆盖已加载名称、链接、原消息与作者；Agent 默认只查爱心认可，可指定 `favorites_only:false` 和 `load_more` 扩展范围。仅展示有权访问的当前频道／Solo产物；归组保留全部原文件和来源，支持切换及解除归组。

入库搜索为标题、标签、来源元数据的字面检索，不包含OCR、转写、网页全文采集或语义检索。当前32 MiB单文件、256 MiB个人声明容量、10000条记录；相同来源同内容幂等重试，冲突保留原记录。入库标记表示曾完成服务回读，不表示文件已共享给全员。
