# 聊天产物 2.0

版本：**2.0.0-rc.5，候选版**。插件 ID `opcb.chat-artifacts`，API v1。
唯一维护与分发源：[OPCB-Plugin-Center](https://github.com/monoly0218-arch/OPCB-Plugin-Center)。
未完成两台 Mac 的原生安装与真实附件验收，不能作为正式 2.0 已发布的证明。

在当前聊天标题栏点击「产物」，从右侧独立圆角侧栏找回文件、图片、视频、文档和网站链接。宽屏保留左侧聊天；窄屏由宿主切为覆盖式侧栏。关闭按钮与 Escape 返回聊天入口。

## 本轮界面更新 rc.5

采用共享笔记 opcb-ui-standard-v3 的固定基线 efe1d1e33787bf7fa44f33d70fe3e46402ce7a98：16px 圆角、Nunito 英文与数字、Resource Han Rounded 中文内容标题、44px 主要控件。字体真实内嵌，不依赖 CDN；控件沿用系统字体，深浅主题读取宿主变量。

channelPlacement 改为 side，不再占用聊天标签页。该公开 API 在 Studio 实际 1.0.1 的 useChannelPanels / PanelDock 中支持，打开、动效、窄屏覆盖与焦点返回由宿主负责；插件只绘制侧栏内部的圆角表面，不改全局 CSS 或宿主源码。默认紧凑列表，可切卡片；搜索与类型筛选保留，认可按钮移到标题行，知识库待接入提示合并在页尾。收藏、分组、缓存命名空间与 Agent 工具不变。

## 本轮增加：认可和版本

本轮按潘涛 2026-11-14 最新指令，先独立交付聊天产物：Agent 查询、爱心认可、版本归组。综合知识库由另一 Solo 会话执行，入库接口后续再接。本包不依赖知识库服务，也不申请该服务的网络或身份绑定权限。

- 人或 Agent 可用爱心收藏认可具体版本；记录操作者与时间，Agent 标记明确显示“Agent 认可”。收藏是操作者的判断，不自动成为其他人的审核结论。
- 选择多项并填写成果名，可折叠为一张成果卡，按归组顺序显示 V1/V2/V3；可以切换当前版或解除归组。归组保留全部原文件与来源，不对图片进行像素合成，不凭同名自动合并。
- `opcb_artifact_search` 默认只看认可产物，返回来源、操作者和版本；`favorites_only:false` 可查其他结果，`load_more` 每次最多扩展五页历史。
- `opcb_artifact_favorite` / `opcb_artifact_versions` 使用查询返回的 `revision` 执行操作；冲突要求重新读取。调用必须来自当前账号所属 Agent、当前频道或 Solo，并以 Agent 身份核对每条来源。
- 索引/文本仍用插件本机缓存；认可和分组改用宿主 ArtifactStorage 的设备 preferences，同一设备上的界面和 Agent 共用，不宣称跨设备或全员同步。旧收藏一次性迁入，原 Web Storage 键保留作回退依据；后续标记以新存储为准。

界面中的“知识库接口待接入”为禁用状态；没有可调用的 Agent 入库工具。历史确认回执可以保留为历史记录，不代表本版已经联通知识库。后续边界见根目录 CHAT_ARTIFACTS_INTEGRATION.md。

## 这次解决什么

1. 加载更早历史会累计追加，保留最新产物；重开先显示本机保存的清单，再同步变化。
2. 搜索覆盖已加载产物的名称、链接、原消息内容和作者；支持多个关键词与全角字符。
3. 卡片和列表显示作者、时间与线程来源；文件直链按图片、视频、文档分类。
4. 保留 Agent / 已分享文件 / 全部产物范围、类型筛选、收藏和原生来源消息预览；收藏写入失败明确提示且不伪报成功。
5. 新增、编辑和删除从宿主精确消息读取结果同步；断网保留已加载内容，撤权清空展示，关闭后释放订阅。

搜索覆盖**已加载**历史。继续点击「加载更早产物」可扩展范围，不声称已经检索整个频道。
文本和 Markdown 只缓存前 64 KiB；图片与视频复用宿主媒体能力，完整文件不保证离线。
链接可被提取不代表目标网站有效、公开或已获得访问权限。

## 数据、权限与兼容

只读取当前有权访问的聊天，不申请主机命令、进程、通用文件系统或额外网络权限。
本机索引和文本缓存使用插件自己的 IndexedDB，按社区、账号、频道隔离。
旧收藏从 `opcb.chat-artifacts:stars:v1:` 一次性迁入宿主设备 preferences；不迁移其他客户端或账号数据，不承诺跨设备同步。系统清除网站数据可能删除本机缓存。
失效阅读权限不会由缓存授予；重连仍需宿主确认权限。本机缓存是读取副本，服务端聊天仍是权威来源。

本轮核对官方最新发布 **v1.0.2**；Studio 安装包 **1.0.1 / 1.0.1**，对照该版本公开 `session.readRemote`、`session.thread({exact:true})`、Relay、panels、navigation 和 conversation UI 契约。
未升级或重启宿主。先支持 macOS 候选验收；MacBook、Android、iOS 未验收。
