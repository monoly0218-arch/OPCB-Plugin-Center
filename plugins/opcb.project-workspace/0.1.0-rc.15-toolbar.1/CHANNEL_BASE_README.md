# 任务中心-测试版 0.1.0-rc.15

左侧统计、中间负责人频道列表、右侧执行会话构成三个主要空间。延续 rc.13 的绿色频道胶囊、紧凑分组、无表头和无频道搜索；原频道关联与业务负责人保持。

## 直接调节空间

移除齿轮及比例弹出设置。两条20px空白间隙是可拖动分隔线：左侧间隙调整统计整体宽度，右侧间隙调整会话宽度，中间自适应。默认仍为统计256px、会话320px，统计模块高度220px。左侧是透明整体容器，内部三个模块共享宽度；底部空白可统一调整模块高度。静止时不画容器边框，悬停/拖动时才出现细线。

统计宽200–400px，会话宽260–640px，中间至少340px；窗口收窄时自动限制两侧宽度。统计高度180–300px，拖动以三个模块的合计高度换算；不分别添加卡片调节器。双击或Home恢复该方向默认值，方向键微调8px，Shift微调32px，Escape或pointercancel撤回本次拖动。Pointer capture保证跨出间隙仍可拖动，结束释放；无全局拖动监听。比例在当前打开期间保留，不写业务记录。

1390px及以下会话移至列表下方，对应间隙改为上下调会话高度（320–1000px，默认600px）；850px及以下三个空间纵排，统计模块横排，隐藏不适用的左右宽度间隙。统计整体下方仍可调模块高度。ResizeObserver跟随宿主容器尺寸并在卸载时清理。

## 创建天数

采用北京时间自然日，创建当天计第1天，显示「1 天／2 天」。每30秒更新，跨上海午夜递增，不再显示分钟/小时，也不使用旧start、更新时间或活动时间。悬停说明创建日期和第1天口径。

原生ChannelSummary.createdAt优先。原生创建时间缺失时，可从频道Canvas读取明确登记的createdOn（YYYY-MM-DD）与createdOnSource（本人确认消息链接），不虚构时分秒。日期/来源严格校验；无来源日期不进入回退，未来日期/时间未知。月新增、周新增使用相同来源，按上海日期、周一开始统计。看板仍不提供手填开始日期。

四频道的本人确认日期已在上一轮写入各自私密Canvas并保留原文、负责人、空进度与旧start等字段；本次不再改业务资料。真实宿主频道创建时间未更改；私人频道ID与业务数据仅保留于授权会话与隔离预览，不进入公开源码/包。

## 权限与验证范围

官方Buzz 1.0.2/API1及本机1.0.2已在本轮核对。继续复用原生React/pages/panels/relay/conversation/navigation API，无新宿主权限/服务。schema1向后兼容；只读、HEAD/revision冲突保护、preserveApproval和撤权隐藏保留。

铃铛仍是逐频道进入会话的提醒清单，不群发、不自动发消息或邀请成员。原生安装及实体移动端待验收。本版按本人要求作为测试版发布到正式插件中心目录，名称及原生入口统一为「任务中心-测试版」。插件ID保持opcb.project-workspace，与原任务中心opcb.task-center并存；不改变BASELINE、历史CATALOG或19项已安装快照。安装通过固定分支与提交的Buzz原生审核，用户确认后才能声称已安装。
