# 任务中心 2.0.0-rc.16

1. 两栏之间的分隔线支持鼠标、触控笔和触控拖动，自由分配任务与会话的宽度；保留两边的最低可读宽度。方向键可微调，Home/End 到边界，双击或 Enter 恢复默认。本机按账号及社区记住比例；900px 及以下仍用原有 Today／右侧面板切换。
2. 每项任务保存上次明确选择的执行会话，切换任务、刷新或重新打开后恢复；尚未绑定的任务保持空白。绑定保存在原 Canvas，其他有权设备重新读取同一来源即可取得；不会创建第二份业务数据。目标不可访问时提示，不跳到别的会话；明确清空会保留空选择。
3. New Solo / Open Solo 仍复用原专属会话，并把这次打开记为当前绑定；不发消息、不自动开工、不改变任务轮次、状态或验收。原生 Workspace、姓名头像、活动状态、Composer、Agent 选择、草稿与 Task 菜单继续由 Buzz 接管。

绑定保存前核对当前账号、来源权限、目标会话权限、验收人、任务轮次、移除状态与 Canvas 版本；失败不伪装成功，不自动重复写入。改绑后 Agent 只可在当前明确绑定的执行会话操作，关闭任务页后仍可凭任务 ID 读取；多任务共用会话时须提供 task_id。旧 Solo 与历史记录保留。无新增宿主权限。

兼容官方 Buzz v1.0.2 / API1。完整检查入口 `npm run ci`，打包 `python3 scripts/package_release.py`。使用官方真实 Workspace／Composer 与隔离数据核对拖动、任务切换、持久恢复及草稿；不向真实业务会话发送测试消息。安装保留本人原生审核，实际业务会话与实体 iPad 手势待安装后验收。公司看板及旧候选包保留。
