## 数据边界

唯一来源仍为原工作进度频道Canvas。读取、查找、成员权限、Canvas核对后保存、版本冲突、撤权与验收身份检查不变；没有新host权限或外部网络依赖。未登记日期不排进Today或未来日期；旧计划中的D0、15/17日备选及建议钟点不自动转成确认排期。

现行正式执行记录只登记日期，没有已确认钟点字段。生产日历将这些工作列在「时间未登记」区，不编造小时位置。离线样例的钟点全部是明确标记的演示值；本轮没有扩展共享执行记录格式或写入正式数据。Notes/Events菜单保留位置但明确禁用，独立笔记/日程来源未接入。
