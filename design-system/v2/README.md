# OPCB 原作校准候选 v2

修正 v1 与参考图的结构差距，保留 v1 作为旧工程候选，不修改已安装插件。

- Woday：同一批英文任务、同一 1131×742 工作画幅重建列表详情和日期看板。此画幅只是 2262×1484 参考图片的半尺寸工作假设，不是已恢复的原生逻辑分辨率。
- Sphere：共享浅色工作面内的宽集合与当前内容双栏；分类色、软阴影和选中项目有独立规则。原图含折叠设备框，不能用整图和工作区直接计算视觉相似度。
- 中文知识库：从上述结构派生，标题30px、资料标题15px、正文16px/1.75；与英文的32/14px分开校准。中文仍为系统无衬线，不宣称恢复原作圆体。

打开 [PREVIEW.html](PREVIEW.html)，切换页面、语言、主题和状态，可展开原作参考。英文内容来自公开原作，中文内容为虚构演示。完成勾选仅在当前页面内保留，刷新清空；问答和排序入口明确提示演示范围。参考图片使用已发布的公开素材URL，需要联网；界面自身不加载脚本、字体或业务服务。

## 复用

使用 `tokens.css` 与 `components.css`，所有选择器作用于 `.opcb-v2`。从 `react.mjs` 调用 `createUI(ctx.react)`，复用宿主 React；它不访问网络或磁盘。已有 v1 插件仍可继续使用，不被 v2 自动覆盖。

`Header` 只保留标题、必要副标题和工具。`Group` 在左侧标注分组；`Board/Column` 使用工作面直接承载卡片，禁止另套灰底列容器。`Item` 分开完成按钮与打开内容按钮，内容身份可传图标或缩略图，不能把所有对象统一成同一文档图标。`Dual` 放在可用全宽区域，避免再套入带内边距的 Workspace 主面板；应用可直接沿用预览的 `.v2-shell/.v2-content` 组合。

`Workspace` 的高度由插件容器提供，不能依赖整个窗口。小于850px收起导航，小于620px详情替换主区，Sphere集合与当前内容单页切换。返回按钮、Escape与焦点恢复由业务消费方实现，CSS不模拟完整导航或授权逻辑。

默认采用 `theme=host`，公开宿主变量仍需当前设备验证；预览显式使用light/dark。深色是OPCB适配，不是原作截图证实的状态。触控按钮至少44px，图形可小于点击范围。选中轮廓与蓝色键盘焦点分开。

构建：`node design-system/v2/scripts/build-preview.mjs`。交付离线含原图版本可指定 `OPCB_REFERENCE_ROOT`，不提交研究目录或本地路径。候选源码与各业务插件版本、目录默认项和安装状态分别管理。

证据与边界见 [SPEC.md](SPEC.md)、[VALIDATION.md](VALIDATION.md)。缺少Woday原生程序，未恢复真实字体、精确Token、动效或内部状态机；本轮为基于公开截图的视觉重建。
