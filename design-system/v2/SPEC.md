# 原作校准与复用规则

## 五项方向

产品是插件自有工作区；性格安静直接；场景包括资料浏览、任务与集合；重点是内容身份和当前对象；识别细节是近黑框架、直接承载内容的近白工作面，以及按需打开的详情。Sphere模板保留宽双栏的另一种组织方式。

## 交互与内容

1. 完成与打开分为兄弟按钮，完成保留视图与键盘焦点；不同任务共享同一个ID和当前状态。日期看板中的重复周期任务只是同一演示对象，不代表真实实例模型。
2. 搜索只筛选当前演示视图；切换页面清空搜索。打开正文保留对象标题，返回集合；窄屏关闭详情回到对应对象的按钮。无权限、错误、空、加载分别表达，状态切换清除详情，不露出先前正文。
3. 选中轮廓表达当前对象；蓝色外轮廓表达键盘焦点。44px点击范围内可以容纳19px图形。分类颜色必须配文字；绿色研究类与任务完成状态分别表达。
4. Sphere宽集合与内容是完整模板，不能把集合缩成宿主式导航；窄屏先选集合再进入内容。软阴影限定在Sphere分类与标签，不传播到Woday列表/看板。
5. 全部文字为公开参考或虚构演示；不据此推断真实业务进度，不添加虚构封面或数据。问答、排序未接业务API时明确提示。

## 接入约束

v1的15个插件接入映射继续作为范围清单，v2只修订自有工作区的呈现规则。业务授权、宿主导航、聊天、Browser View原站和安装审核不受此CSS影响。不同业务沿用同一基础样式，布局在分组列表、直接卡片看板、宽双栏之间按内容选择。正式接入前须核对当次官方宿主版本、公开API、目标设备实际版本及宿主主题；本轮没有修改运行中的业务插件，因此未重新申请设备安装或升级。
