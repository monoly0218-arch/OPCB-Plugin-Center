# v3 检查与边界

用户本轮明确要求不用界面设计Skill，严格依照参考方向和标准。已据此校正先前统一平面对象图标的做法：Woday对象为固定立体图像替代，Sphere分类为彩色实心符号；菜单与设置符号分别对照原图。没有继续调用设计Skill产生新的风格建议。

## 已检查

1. EGO逐页切换21个视图：19个原作页面／状态、字体样张、中文知识库适配。1131×742截图没有整页横溢，正文非空，弹层状态可见；结果见PAGE_CHECKS.json。截图检查不等于全部像素相似度验证。
2. 24项实际网页交互：勾选与焦点、对象详情/返回、搜索空结果、笔记身份、编辑后选图标保留正文、弹层inert/搜索/关闭焦点、日期选择、外观设置、明确的本页创建反馈、Sphere集合、中文阅读、无权限清理、390详情与双栏返回、局部横向滚动和弹层宽度。见INTERACTION_CHECKS.json。
3. 浏览器CSS.getPlatformFontsForNode确认数字分别由OPCB Nunito与OPCB Quicksand实际渲染，中文由OPCB Round SC Bold实际渲染；不是只检查CSS字符串。Nunito 28px/700的0–9单字advance均16.8046875px，证实本次tabular设置有效。见FONT_CHECKS.json。
4. 390、768、1024、1440容器的21视图共84次布局检查无整页横溢，弹层边界均在容器内。见RESPONSIVE_CHECKS.json。
5. 字体WOFF2与MIT PNG逐文件哈希、授权、页面清单、共享包不夹带审阅工具栏由Node检查覆盖。完整仓库检查入口npm run ci，分发清单python3 scripts/package_release.py。

## 尚有限制

精确原生字体、动效、完整3D图标库和后台状态机没有取得。本轮Nunito/Quicksand/资源圆体为明确替代；Fluent图像也未证实等于原作者资产。原图封面使用审阅图像区域呈现，不交作正式业务素材。部分未接通业务的控件只给出明确演示反馈，AI为预置参考文案。不能把本轮候选称为Woday官方设计系统。

本轮仅design-system/v3、索引与对应检查；保留v1/v2。没有修改业务插件、服务、目录默认版本或安装状态。网页390/768等容器模拟不代表实体iPad、Android或Buzz原生验收。候选同步、默认分支合并、业务迁移和安装审核仍分别报告。
