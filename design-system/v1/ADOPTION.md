# 在 OPCB 插件中采用这套标准

这是可以编译进各插件的共享设计源，不是一个安装后改写全部插件的全局主题插件。实际迁移沿用每个插件的业务与授权边界。

## 集成方法

1. 使用 `tokens.json` 的语义值与 `tokens.css`，在插件业务容器包裹 `.opcb-ui`；默认 `data-theme="host"`。外层 Buzz 窗口、聊天与审核保持宿主原生结构。
2. 把 `components.css` 作为静态文本编译入包；`createUI(ctx.react)` 接收宿主已有 React。`StyleSheet` 只接收编译时传入的 CSS，正式使用前核对当前宿主的 CSP 和允许的样式接入方法。
3. 页面选择适合任务的模板，业务层负责数据加载、权限、搜索、写入和状态回读。共享组件不存储账户、密钥或业务资料。
4. 使用插件容器的宽度切换布局；侧边面板与 Agent 设置 tab 直接使用组件和表单，不再嵌一层完整工作台。
5. 每项迁移分别走完整检查、分发和原生审核；安装完成后再记录实机业务验收。新增共享源不会自动升级既有插件。

## 逐插件映射

| 插件 | 首选模板与组件 | 迁移时保留的契约 |
| --- | --- | --- |
| 知识库 | 集合、对象行、预览、正文、来源卡片 | 个人授权、Agent继承读取、缓存状态与来源时效 |
| 知识库管理 | 人员列表、权限详情、设置、审计 | 管理独立授权、继承与显式规则、保存回读与冲突 |
| 插件中心 | 目录、版本行、依赖详情 | 固定来源与版本、原生安装审核 |
| 聊天产物 | 紧凑列表、类型筛选、预览 | 原消息与频道权限；不重绘宿主消息本体 |
| 任务中心 | 对象行、状态分组、看板、详情 | 当前Canvas数据基线与私人Solo作用域 |
| 公司看板 | 项目/人员分组、数据说明、详情 | 与任务中心共享来源，不产生另一套进度事实 |
| 内容工厂 | 素材集合、筛选、预览、建议表单 | 原站登录和用户确认保存；Browser View内部另适配 |
| 上粮山资产库 | 媒体卡片、属性、缺失/过期状态 | 空白分发状态、原件与原站登录不由UI补造 |
| 上粮山电商 | 原站外壳、工具栏、状态 | 真实经营数据、原站界面与权限由原服务负责 |
| 热点工厂 | 看板、步骤、候选行、详情 | 未接通的采集/制作/统计继续明确不可用 |
| 选题灵感 | 主题画布周边、筛选与对象详情 | 保留特殊画布交互，提供文字路径与减弱动效 |
| 成果报告 | 正文、章节、表格、来源 | 真实值缺失时留空；模拟数据单独标注 |
| Higgsfield号池 | 账号行、遮蔽值、收码状态、表单 | 1.3/1.4同ID升级关系、密码隐藏与各机后端差异 |
| Muse连接器 | 连接表单、诊断、状态 | 桌面依赖和独立配对，不包装为移动端可用 |
| Grok Bot连接器 | 地址、凭据输入、回传状态 | 发送/回传/监听分开；密钥不进入样式包 |

本轮仅产出标准和共享实现，上表各插件的实际迁移均未执行。

## 承载范围

- 原生 React 业务页：可以直接复用布局、对象行与状态组件。
- 原生侧板或 Agent 设置：复用紧凑组件、字段与状态，省去重复导航。
- `ctx.browser.View` 原站：插件只控制外壳，无法凭本库改变跨域原站内部。
- 宿主聊天、安装审核卡和系统窗口：继续采用公开宿主能力，本规范不改变这些区域。

这些界限来自当前中心 `4dd8a8e08cac922b058bbf3a214159198507cbb2` 代码。支持某种CSS写法不等于已经在iOS/Android实机验收。

## 版本与验证基线

本轮查询官方最新发布为 `block/buzz-app v1.0.2`（2026-11-13）；Studio当前 `Buzz.app` 为 `1.0.1`。只读取版本，未升级或重启。源码快照的manifest声明 `apiVersion: 1`。本轮预览为独立网页，不把网页通过写成两版宿主的兼容验收。

源码实现 `1.0.0-candidate.1`，迁移插件应锁定共享版本。新版本改变布局、状态、可读性或交互契约时须写迁移说明，不能静默更新全体。

验收至少包含：显式深浅主题＋真实宿主主题；完整标题和长摘要；插件容器宽度1440/1024/768/390；键盘焦点、Esc、返回；空/错/无权限/加载；真实写入成功、失败和权限变化。仅有截图时不勾选数据闭环。
