# 候选验证范围

本候选为独立共享源与网页样例；不是已安装业务插件。

## 检查入口

- `node design-system/v1/scripts/build-preview.mjs`：生成无外部依赖的交互预览。
- `npm run ci`：中心完整入口，覆盖语法、全部Node测试、完整知识服务Python测试和分发校验。完整回执绑定交付提交，随交付包提供。
- EGO：对独立预览执行实际点击、输入、视图、宽度及主题切换；浏览器结果回执随交付包提供。

## 已检查内容

共享组件的CSS作用域、Token引用和主题一致性、主按钮及状态文字对比度、宿主React注入、非嵌套按钮、Field关联、图标可读标签、Workspace状态。

独立网页的六种场景，以及列表与正文切换、对象身份、搜索空结果、集合搜索、错误/无权限、局部滚动、详情关闭和返回焦点、逐身份的本地设置、重复搜索快捷键。1440及1024主/辅布局、768和390详情替代主区分别核对。

独立审查发现并修复：不同资料打开同一正文、人员示例状态串用、重复快捷键焦点丢失、集合搜索空白、相关资料连读返回目标覆盖。额外修复搜索时替换输入节点影响输入验证的问题。

原图来源、图片色值取样和REA归档身份检查见EVIDENCE.md；这些不是原生程序反编译。

## 未验证范围

真实Buzz插件中的样式接入/CSP、宿主主题实时变更、iOS/Android原生WebView与Browser View、读写业务与权限回读、全插件迁移、安装审核和实机验收。不能从独立网页检查推广为这些项目已经通过。

主按钮白字约6.21:1；显式主题的状态文字均高于4.5:1。宿主继承主题的最终颜色需在采用插件中核对，未声称整页WCAG审核完成。
