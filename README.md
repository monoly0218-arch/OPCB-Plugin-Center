## 写回与真实性

官方1.0.2公开 session.canvas.save(channel, content, expected, {preserveApproval:true}) 提供原生签名、版本冲突检查、回执和实际回读。本版使用它向原 Canvas 末尾的 opcb-task-execution-v1 区追加执行记录，保留原计划原文与既有记录。冲突/权限变化拒绝覆盖，界面保留草稿；不自动重试。草稿不持久化，重载应用后不保留。源频道原生版本历史是追溯依据，JSON中的登记字段不是独立签名证明。

当前可写成员才能登记；「已验收」仅允许来源频道创建者本人选择，且需要交付链接及非空验收说明。不能把待验收当完成。此限制不扩大原生频道权限。Agent工具仍只读。旧宿主无save或无写权限时表单不可保存，不假装成功。

15日/17日备选、D0和建议钟点不自动推断日期；缺失日期/状态仍明确未登记。只有本人明确保存的合法年月日进入月历。不改预算、审批结论、知识权限或任何正式任务事实来演示功能。
