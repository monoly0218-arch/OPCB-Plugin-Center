# 潘涛的收藏 · 0.1.0-rc.1

在 Buzz 侧栏打开「潘涛的收藏」。应用使用所在社区的原生频道、媒体和发送接口。当前账号须能访问同名私密频道；读取本人及本社区本人 Agent 发布的结构化收藏简报附件。

- **汇报**　左边看收藏汇报和「这一期先看」，右边随期次与精选常驻预览。保留原帖、配图、已取得的视频、近期工作关联和采集口径。
- **收藏**　左边搜索完整清单，右边 Inbox 保存每条执行草稿。选好 Agent，点击「执行」后把本次写好指令的收藏发往一个新的私人 Solo。空白指令留在 Inbox。发送确认仅表示 Buzz 收到，可到 Solo 查看 Agent 的进度。
- **行动**　左边选执行建议，右边先展示依据收藏，再展示自然语言建议。两、三、四条来源分别并排，项目名称用粗体显示。

Inbox 草稿与发送收据按 Buzz 账号、社区和频道在本机保存。已提交的 Solo 和消息由 Buzz 同步。发送结果待定时通过「核对原发送」或「打开原 Solo」继续原批次。插件无需外部服务、网络白名单或本机文件权限，按原频道已有的访问权限加载。

验证基线为官方 Buzz 1.0.5 API 1 与 Studio macOS Buzz 1.0.6-preview.1。发布包通过 Buzz 原生审核安装。移动端须在目标设备上验收。

界面方法参考 Damir Sokolovsky 的 [Unslop](https://github.com/heydamir/unslop)（CC BY 4.0）。适配与实施：潘涛 Studio。
