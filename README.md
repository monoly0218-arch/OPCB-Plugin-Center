# OPCB 平台商业化计划与报告 · 2.0.0-rc.15

打开「需求与模板」查看「模版工厂交付」。工作台使用当前已登录的 Buzz 身份和频道权限读取单件交付。打开工作台或点「更新数据」会读取最新记录。同一任务重复回传同一份附件时，保留第一条有效交付作为验收目标。

小莫在对应交付消息上点 👍 后，刷新可见「已验收」。撤回 👍 后，若没有其他有效验收，刷新会显示「待验收」。退出对应社区或失去频道读取权限时，面板停止展示记录。

后续新增交付可由潘涛在频道发送，或由 Studio Agent 引用潘涛在频道的原授权并回传。回执需含一个原生附件和独立的 `work-sync-task: <任务 ID>`、`work-sync-title: <名称>` 两行。Agent 回传的授命消息须包含相同的任务 ID。两条试点回执保留原授权。客户端直读要求官方 Buzz v1.0.5 的原生读取和精确消息接口。

发布日历把未排期成品、月份和导航并入标题栏。保留月历与发布详情。任务为空时也可搜索、筛选和切换 List／Gantt，目标与预算继续显示。

本人授权的审阅附件可补充商业化分工、交付步骤与待发排期。已清理的历史内容仍按精确 ID 过滤，正式任务状态以共享来源为准。分发包不包含分工、排期或私人媒体。

参考视频和成果同处一个圆角框，制作回执在成果标题旁。评论在右下弹出，沿用 Buzz 当前身份与本地草稿。

体验模式在标题右上，可先浏览流程步骤。macOS 使用官方 Buzz Browser View 和 Python 3 的随机回环端口预览已绑定的原稿。预览不写磁盘，原稿在隔离框中运行，关闭工作台或撤销来源权限时关闭预览进程。更新审核会显示本地 Python 预览权限。

报告仍从按身份和社区隔离的本地缓存打开，用「更新数据」读取共享内容。兼容官方 Buzz API v1。
