# 内容工厂 2.0.0-rc.13

内容工厂使用灵感收集、素材确认、制作中、待审核、待发布五个阶段。保留素材认可和数量。下载队列、已收起移入灵感收集筛选。

进入制作先把素材流转到制作中并记录当前成员认领，然后打开本人的专属 Solo。已有制作接续原版本。其他成员看到灰色卡片，可主动加入并新增一条独立版本历史。团队只同步认领人和版本编号、状态，私人会话和草稿留在原 Solo。

成片由制作人在原 Solo 验收后，可将对应成片和工程包一并提交团队审核。退改意见按制作版本和审核人带入本人的下一版备注。通过的制作版本在待发布可下载成片和工程包，另一位继续制作时仍可下载。

API 1。含多人认领、版本索引和交付的功能要求配套 AdFlow /ins 服务更新。旧服务仅支持已有制作及从素材确认开始制作。本机 Buzz 1.0.6-preview.1、官方参考 v1.0.5。成片与工程包上传使用原有 Python 3 宿主进程及同源服务。最终安装走 Buzz 原生审核。
