# 任务中心-测试版 0.1.0-rc.23

## 团队协作

任务、进度、会话和产物仍使用原频道。两位同事加入同一个项目频道，便从同一份频道资料读取。Buzz 的公开频道浏览只显示可加入的入口；加入后才按当前身份读取 Canvas。源频道未加入、权限未生效、仅为缓存或已有退群时，插件不读取资料。真正的已加入频道加载失败仍提示刷新。

在「共享目录 → 查找并加入公开频道」可查找当前社区的公开频道，并自己点击加入。公开共享目录按宿主实际能力要求读者加入，guest 可读取目录；工作频道需普通成员或有写权限的角色才能发消息。私密频道仍需管理员邀请；只展示管理员主动登记的公开名称和品牌。频道创建者和当前资料管理人可以更新任务资料，编辑沿用原来责任分工。

## 紧凑布局

看板、频道空间、产物页、使用指南和表单统一收紧字号与留白。看板在 13 寸和宽屏窗口保留左侧统计、中间任务、右侧执行会话。缩小各区默认尺寸，三处拖动调节继续可用。任务与消息列表各自滚动，聊天输入框留在右侧会话底部。更窄的分屏按可用宽度调整。

官方参考 Buzz v1.0.5，本机 1.0.6-preview.1，插件 API 1。原生安装或更新由设备用户审核。真实跨账号业务、保存和人员权限须在各自 Buzz 设备验收。设计方法、字体与 3dicons 许可沿用前版。
