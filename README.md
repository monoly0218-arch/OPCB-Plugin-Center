负责人之间增加中性细分隔线，每位负责人的任务沿左侧同一条浅灰竖线对齐；姓名与数量在一起，组内8px、组间24px留白。绿色仍只用于当前频道。中间较窄时姓名移至组首，保持相同归属线和组间边界，不增加彩色负责人卡片。

## 会话常驻与滚动

看板使用宿主实际分配的高度。取消看板的整页纵向滚动，任务列表独立滚动，执行会话约束在可用高度内；原生会话继续负责历史滚动与输入框。没有复制输入框、定制聊天协议或固定到整个操作系统屏幕。

- 1080px及以上：三个空间并排，默认统计模块256×220、会话320px；左右间隙直接拖动，保留统计整体高度调节。
- 700–1079px：统计压缩为顶部一行，下方任务和会话并排，二者间隙调会话宽度。聊天不再落到任务列表末尾。
- 小于700px：统计简排，任务上方、会话下方，两区都在当前视口内。间隙调整分区高度，限制会话高度以保留任务可读区域；输入框仍留在会话底部。

任务列表及原生聊天历史各自滚动，统计内容超出左区时只在该区滚动，不把整个页面撑长。窗口或提示条改变可用高度时重新限制比例。支持键盘、双击/Home复位、Escape取消和指针捕获；刷新、主题、打开频道、登记进度与原权限逻辑保留。没有新增搜索、自动群发或改动业务资料。
