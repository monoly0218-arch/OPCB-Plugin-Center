# 任务中心-测试版 0.1.0-rc.21

页面左下角保留“使用指南”胶囊，占独立页脚行，不遮挡聊天输入框。指南一更新进度、指南二早晚更新、指南三看清卡点；每项给出可复制提示词、对应Skill及预期结果；复制时附当前品牌项目链接，卡点指南只附当前选中项目，避免Agent找错范围。可以复制随包的通用Skill规范，未配置Skill的其他设备也能把规范交给自己的Agent；打开和复制不会自动发消息、保存任务或设置定时。复制失败时保留可选中的正文并提示手动复制。

一句话进度采用本人选定的A版自然口语，像同事平时汇报，直接说做到哪、还要做什么。少用“已交付”“待核实”等书面说法；保留40字、前18字后20字的两段式，以及事实、权限与回读边界。“还没确认”不等于“还没做”。使用指南的结果说明和随包Skill同步采用此规范，保留三条提示词和项目链接。

随包ONE_LINE_PROGRESS_SKILL.md只含通用写作与授权边界，不含本人的频道绑定、账号、定时记录或私人数据。本机已有9:30/18:30日程不重复建立，其他设备需各自授权和配置。

一句话进度限40个Unicode字符（含标点），单行填写，实时显示字数，超限提示并阻止保存；模型保存边界同样校验，覆盖频道和分项任务。历史长进度仍可读取，编辑其他字段时原样保留，不自动截断；新建和改写进度使用40字规则。

每位负责人使用一个浅底圆角整体模块，姓名、数量和任务在同一块底色内，以间距和表面区分归属；不再用组间横线或组内竖线。未加入的锁定入口沿用同样的模块结构。深浅色和窄容器分别适配，绿色仍只用于选中的频道。

管理员可以主动登记允许共享的私密任务频道名称。未加入的人在管理页看到「私密 · 未加入」的锁定入口，至少知道任务频道存在；点击提示联系频道管理员邀请。没有自动加入，也没有伪造原生私密申请审批。

## 共享与权限

共享目录使用当前社区公开频道的原生Canvas，以opcb-project-directory标记保存。记录只含目录schema/revision/id，以及每项的channelId、title、company；拒绝进度、聊天、产物、成员等额外字段。每项名称可另填公开别名。公开插件包不带私人频道ID或账户运行配置。

入口在看板右上角「共享目录」。管理员选择自己管理且已登记为任务的私密频道，填写允许共享的名称和品牌，明确勾选「允许当前社区成员看到上述名称和品牌」后登记。保存和撤回都只修改共享目录，不改原私密频道、成员、可见性或业务进度。未主动登记的私密任务不会自动公开。

维护者必须同时具有共享目录的当前管理员权限，以及目标私密频道的管理员权限，且已加入、可写；撤回自己有权维护的目录项不要求继续持有目标权限。普通目录读者不能修改。原生目录频道建议公开、默认新加入者为guest，管理员另授owner/admin；Canvas和成员权限仍由宿主及relay执行，插件不代替授权。

未加入的读者仅从可读共享目录取得名称，不请求私密频道Canvas、历史、进度、产物或成员。入口不是访问许可；资料管理人与频道管理员不是同一个授权概念。获邀加入后，重新核对原生权限，原任务正常出现且不会和锁定入口重复计算。共享目录撤回、变为私密、撤权、缓存或身份切换后，锁定入口随之移除；旧异步读取不能恢复它。

共享目录可有多个，界面选择相应目录；同一目标按目录ID稳定去重。总数含锁定任务；月/周新增只计有权核实创建日期的部分，缺失部分保留≥或未知，不从目录登记时间伪造频道创建日。共享名称在单独的「未加入」组，保持原有负责人分组，绿色仍只用于已选频道。

## 实现与兼容

复用react/pages/panels/relay/conversation/navigation和原生Canvas；apiVersion1，无新服务、运行依赖或宿主修改。官方本轮参考v1.0.4，Studio实际1.0.5-preview.2。沿用rc.16公开未加入可见、点击加入、真实频道同源同步、负责人浅底圆角模块、任务独立滚动、输入框常驻和三空间拖动。

不提供无权限私密频道的自动发现；管理员登记名称是必需条件。此版本没有私密频道申请/审批原生接口，实际加入仍需管理员邀请。新设空共享目录只启用维护入口，不等同已分享任何真实私密频道。
