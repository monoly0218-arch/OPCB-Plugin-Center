# OPCB 平台商业化计划与报告 · V3

版本2.0.0-rc.4，沿用ID `opcb.results-report` 与页面ID `report`。默认打开品牌增长执行看板，顶部可切换执行看板 / Goals / Timeline / Progress。保留七张页面：看板、目标、任务、内容、报告、视频、手机。工作卡可打开来源明细，旧视频预览及关闭清理保持。

## 共享来源与自动更新

- 与任务中心使用同一工作进度群Canvas：`buzz://channel/7dc199bc-755b-47bb-8f71-fe311b1f1ab1`。沿用任务ID、`opcb-task-execution-v1` 执行区、`opcb-task-checks-v1` 勾选区和明确的日期/时间表。旧完工勾选保持待验收，与任务中心一致，不按日期或聊天推断完成。
- 当前页面可见时每30秒强读取；原生live事件、频道权限变化、回到前台和“手动更新”走同一串行读取入口。来源被撤权、账号/社区变化或读取失败时停止展示旧数据。关闭页面清理所有订阅、定时器和预览资源。不是后台Agent任务调度器，不自动代执行。
- 真实用户、付费、收入和账单没有新增平台采集API。未登记值显示“—”，不拿任务数或样片数推算经营实绩。
- “资料”内可填写真实累计实绩、统计日期与证据，保存到原Canvas独立 `opcb-commercial-report-v1` JSON区，包含 `schema:1, metrics, asOf, evidence, plan`。所有已登记实绩需要统计日期及HTTPS/Buzz证据链接。先读当前版本，冲突保留表单，不覆盖；保存后再次读回确认。页面保存是本人主动操作，Agent未新增写工具。该区不修改原任务、执行区、勾选区、预算批准或上线批准。
- 报告共享区存在时优先读取；否则保留已有本机计划/真实数据并标明“本机记录”。若需共享本机计划，在“资料”核对后保存到共享来源。导入计划仍进入原本机键，不会自动覆盖共享记录。

## rc.2：任务中心 Agent 同步

任务事件 `opcb-task-lifecycle-v1` 在旧执行记录与勾选之后投影，顺序与任务中心 rc.11 一致。读取 create/start/revise/deliver/blocked/reschedule/accept/complete/reopen/remove/restore，保留原ID、轮次、交付版本与验收事实；已移除任务不进入列表或统计，恢复后保留原ID。未排日期任务也列入 Timeline，改期同时更新日期和时刻。详情展示当前交付链接及版本，修改后不会继续显示旧交付。

`src/tasks/lifecycle.mjs` 直接复用正式插件中心源码提交 `18732d7db1ccc43943558a9f2264b24a7f87a077` 的实现，报告只调用其只读投影；没有增加Agent工具或任务写入口。旧任务中心rc.7构建和其他业务插件不变。任务中心未来若升级数据协议，需要重新进行兼容核对；同源不代表忽略协议版本。媒体仍按原权限和本机存储使用。

## rc.4：品牌运营看板

默认进入执行看板：三张品牌方向图片、六段18节点用户路径、内容起草/评价/发布工作流、社群阶段与真实数据卡。分类支持总览/品牌/内容/用户路径/社群/数据，点卡片打开原始动作、修改项和验收指标。完整计划原文保留。

品牌图片由内置image_gen生成，为无真实品牌的方向示意，明确标注，不冒充真实对标或已交付样片；真实对标仍待补齐与评价。内容排程、任务、预算和实际数据读同一来源，缺失数仍显示未知。没有新增广告采集、自动发布、私信、拖拽写回或自动验收。

新增图片已打进自包含plugin.js，无运行时外部图片请求。原权限/插件ID/页面ID/媒体存储不变；深浅色与窄屏在EGO验证，原生安装需本人确认后回读。
