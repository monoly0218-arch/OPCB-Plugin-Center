# OPCB 插件中心 0.3.5

打开目录时自动读取本机原生插件清单，与固定线上目录的包指纹比较：一致显示“已安装”，不同显示“检查更新”；读取失败显示待核验，不把“有这个 ID”当成同版。默认每条产品线路只显示最新发布标签，旧版本仍可在“历史版本”中查看。号池 1.3 与可选 1.4 保持独立，不自动切线。

点击更新后，保留本机已记录的 Git 地址（含 `.git` 拼写），使用目录中固定分支及提交打开 Buzz 原生审核。安装与更新始终由本人确认；取消不声称更新成功，完成后重新读取本机指纹。其他仓库或文件夹来源不会被自动替换；待审核操作先处理现有请求。团队日历入口、原 ID、权限、配置、3dicons 与贡献者均保留。

使用官方文档明确允许插件作用域读取的 `pluginRequests`，仅调用 `forAgent(...).list()`，以当前真实 viewer 归属读取；不通过此服务调用 request/disable/settle 或安装管理。更新仍调用 `pluginInstaller.requestInstall`，不获取凭据、不读取宿主注册表、无本机连接程序、无新增权限，也不改客户端。服务缺失的宿主降级为待核验，原生审核入口保留。

线上 release 指纹按官方 v1.0.5 的公开 Artifact/Manifest 序列化生成，完整包包含 README 和图标。与本机实际 17 项原生安装基线逐项比对；指纹一致说明包内容一致，不宣称签名信任或业务权限已通过。发布固定源的内容与目录保持一致，历史整套基线不改。

本轮参考官方 v1.0.5，本机 1.0.5-preview.2，macOS / API 1；移动端仍需验收。构建 `node scripts/build_plugin_center.mjs`；完整检查 `npm run ci`，含原生指纹校验。目录 release 元数据生成 `python3 scripts/release_identity.py`。本版只更新插件中心，不自动安装其他插件。
