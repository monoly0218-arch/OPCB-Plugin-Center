# 聊天产物 2.0

版本：**2.0.0-rc.3，候选版**。插件 ID `opcb.chat-artifacts`，API v1。
唯一维护与分发源：[OPCB-Plugin-Center](https://github.com/monoly0218-arch/OPCB-Plugin-Center)。
未完成两台 Mac 的原生安装与真实附件验收，不能作为正式 2.0 已发布的证明。

在当前聊天标题栏点击「产物」，找回聊天中的文件、图片、视频、文档和网站链接。

## 本轮增加：认可和版本

本轮只推进三项：Agent 查产物、版本归组、收入 OPCB 综合知识库。三项已实现候选；服务尚未部署，原生安装与两台 Mac 的真实业务验收仍待。

- 人或 Agent 用爱心认可具体版本，记录操作者；Agent 标记显示“Agent 认可”，不冒充人的审核。
- 多个产物可折叠为一张成果卡，显示 V1/V2/V3，切换当前版或解除归组；保留原文件与来源。
- `opcb_artifact_search` 默认只看认可结果；`favorites_only:false` 查其他产物，`load_more` 按需扩展历史。`opcb_artifact_favorite` / `opcb_artifact_versions` 核对调用 Agent 原消息权限和当前 revision。
- 人点击“收入知识库”，或 Agent 使用 `opcb_artifact_archive`，把选定版本保存到同一知识服务的“收藏与产物”。附件上传原文件，32 MiB 上限；普通网址明确收录为链接引用。保留文件类型、来源消息、成果名、源版本号及实际入库操作者。
- 仅在完成保存并按身份重新回读、核对字节哈希后，显示“已入库·原文件/链接”。失败、权限拒绝或不确定响应不显示成功，重试按来源与哈希去重。

认可和版本归组使用宿主 ArtifactStorage 的**设备 preferences**；同机界面和 Agent 共用，不宣称跨设备同步。旧收藏一次性迁入，原 Web Storage 键保留。
入库内容保存在服务端的个人隔离空间，经当前知识库权限核验后可在其他授权设备读取；不自动把私人聊天结果分享给全员。

入库使用独立 `collect` 角色设备绑定，已有只读绑定不能创建或上传。Agent 使用自身原生签名及所属人证明，独立保存贡献设备身份，不复用个人签发者身份冒称 Agent。首次在普通频道入库时可选择一个可写私人对话保存仅含设备公钥/挑战的身份记录；文件来源仍是当前频道。

服务启用见 [综合知识库协议与部署](../../../services/knowledge/COLLECTIONS.md)。聊天插件新增且仅新增知识域名 HTTPS 权限，通过原生审核卡确认。未申请通用文件系统、命令、进程或任意网站读取权限。

## 这次解决什么

1. 加载更早历史会累计追加，保留最新产物；重开先显示本机保存的清单，再同步变化。
2. 搜索覆盖已加载产物的名称、链接、原消息内容和作者；支持多个关键词与全角字符。
3. 卡片和列表显示作者、时间与线程来源；文件直链按图片、视频、文档分类。
4. 保留 Agent / 已分享文件 / 全部产物范围、类型筛选、收藏和原生来源消息预览；收藏写入失败明确提示且不伪报成功。
5. 新增、编辑和删除从宿主精确消息读取结果同步；断网保留已加载内容，撤权清空展示，关闭后释放订阅。

搜索覆盖**已加载**历史。继续点击「加载更早产物」可扩展范围，不声称已经检索整个频道。
文本和 Markdown 只缓存前 64 KiB；图片与视频复用宿主媒体能力，完整文件不保证离线。
链接可被提取不代表目标网站有效、公开或已获得访问权限。

## 数据、权限与兼容

只读取当前有权访问的聊天，不申请主机命令、进程或通用文件系统；入库仅声明现有知识域名网络权限。
本机索引和文本缓存使用插件自己的 IndexedDB，按社区、账号、频道隔离。
旧收藏从 `opcb.chat-artifacts:stars:v1:` 一次性迁入宿主设备 preferences；不迁移其他客户端或账号数据，不承诺跨设备同步。系统清除网站数据可能删除本机缓存。
失效阅读权限不会由缓存授予；重连仍需宿主确认权限。本机缓存是读取副本，服务端聊天仍是权威来源。

本轮核对官方最新发布 **v1.0.2**；Studio 安装包 **1.0.1 / 1.0.1**，对照该版本公开 `session.readRemote`、`session.thread({exact:true})`、Relay、panels、navigation 和 conversation UI 契约。
未升级或重启宿主。先支持 macOS 候选验收；MacBook、Android、iOS 未验收。

若本机已装同 ID 且来自旧 `miaopantao/opcb-chat-artifacts-plugin`，当前官方宿主 update 仍读取旧来源，install 拒绝重复 ID。

移除会删除旧安装产物和宿主回滚记录；源码、版本包及本候选的收藏命名空间保留，仍需安装后实测收藏是否保留。
