# 知识库管理 2.0 候选

插件 ID `opcb.knowledge-admin`，原生API v1，个人管理员专用。按Buzz个人公钥管理库/子库读取权限、个人停用/恢复、名称、子库目录与审计；其Agent自动继承读取权限，无需逐个登记。管理权限不继承给Agent。

管理员资格仅由服务器启动配置指定，安装此插件不会自动成为管理员。首次使用选择可写私人对话，保存仅含设备公钥/挑战的原生签名绑定记录，无密码与12小时登录；使用独立管理设备钥匙，读绑定不能调用管理接口。

载入的是当前社区可见身份（最多200项），也可填写完整个人公钥。姓名仅作显示，授权绑定完整公钥。库权限默认关闭，父库关闭覆盖子库允许；“继承上级”移除本库显式规则。停用个人拒绝该人的所有后续读取及所属Agent读取，不改Buzz账号或社区成员。并发保存冲突需刷新后重试。

新增子库只创建权限目录，不自动采集或导入资料；源映射由受控服务维护。改名不更改原GetNote库名。目录中的库名与阅读页由同一服务器策略提供。

仅声明现有知识域名网络权限，无宿主命令权限，无Agent管理工具。依赖中心services/knowledge身份服务；构建源src/knowledge/admin.mjs，使用npm run build:knowledge。官方/本机版本参考、候选测试与平台边界同阅读插件：v1.0.1/macOS ARM64，原生真实绑定与业务验收仍待，Android/iOS未验证。

固定中心来源和完整commit生成原生安装审核卡，保留本人最终批准。已读信息无法追回，撤权保证后续请求按新ACL检查。不得把本地模拟测试当作生产授权已生效。
