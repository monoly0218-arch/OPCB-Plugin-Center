# OPCB 平台商业化计划与报告 · 2.0.0-rc.9

图谱与详情恢复左右分屏，选择内容后画布仍可见。面板、参考/成果、作品/评论、视频/文案间提供可拖动分隔条，键盘左右方向键调整、Home或双击恢复默认比例。默认按内容与最小可读宽度分配；窄区顺序排列。空成片使用紧凑占位，真实视频保持原比例。

画布8个模块可通过右上拖柄独立拖动，也支持聚焦拖柄后用方向键移动。连线实时跟随，适应窗口包含移动后的节点；重置位置恢复默认。画布平移缩放与节点移动分开。分屏比例与画布位置按当前身份/社区保存在会话存储中，刷新、切换模块后保留。

修复审阅数据与插件共享来源脱节：`opcb_commercial_review_source`读取/关联本人授权的JSON附件，将带统计日期、证据的指标、原文草稿和精确Buzz媒体来源接入同一渲染数据。绑定需本会话本人原请求、当前revision、本人或当前Agent的可读原附件；新旧绑定采用CAS并回读。每次读取核对身份、社区、来源消息和素材频道权限，丢失权限后不释放旧数据。私有内容只保存于本人Artifact来源关联，公包不内置账号、客户数据或私有链接。

正式任务持续读取共享Canvas，不用审阅快照覆盖任务状态。相同日期及更新的正式实绩优先；审阅指标只填补缺失或较旧登记，真实0与未知分开。已保存Buzz草稿优先于导入草稿。所有扩展指标（模板、人物、妆造、笔记、完成率）也支持计划导入导出。网页访客评论保留在原网页，不冒用Buzz身份迁移。

继续使用 `opcb_commercial_mobile_source` 关联当前本人手机原稿；R8原件与Mobile插件绑定保留。评论使用当前Buzz身份、头像、频道角色与原生消息。头像不可用时显示姓名首字。成片、真实发布/领取、自动经营数据采集和内嵌执行会话仍按接入状态，不把布局修复当作业务完成。

保持ID、report页面、Dock、brand-library集合与3dicons V1身份图标。参考官方Buzz v1.0.5（2026-11-18当前稳定）、Studio 1.0.5-preview.2、API v1；不增加宿主命令或网络授权，不修改宿主。完整npm run ci、EGO多尺寸主题与实际拖动/评论操作验证。原生审核安装及真实账号验收分别记录；未安装时不声称已修复本机运行版本。
