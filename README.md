# 潘涛的收藏 · 0.1.0-rc.2

从 Buzz 侧栏打开「潘涛的收藏」。黑色外框、Nunito 与圆体、左右等宽纸面、三段导航、六页翻阅和深浅主题沿用收藏汇报 HTML。

- **总览**　左侧是收藏汇报与「这一期先看」，右侧是当前期次的常驻预览。点精选切换预览，右上角切换期次。
- **收藏**　左侧完整清单保留原帖和配图，右侧 Inbox 逐条填写指令。按「执行」将已填写的条目发送到一个新的私人 Solo。待确认的批次继续使用同一个 Solo 和消息。
- **行动**　左侧选择建议，右侧先看依据收藏，再看加粗项目名后的自然语言建议。两、三、四张图分别并排。

插件读取账号已有权限的同名私密频道与附件，使用 Buzz 原生 Solo 和本人 Agent。Inbox 按账号、社区和频道保存在本机。验证基线为官方 Buzz 1.0.5 API 1、Studio macOS Buzz 1.0.6-preview.1。安装须本人在 Buzz 原生审核确认。

界面方法参考 Damir Sokolovsky 的 [Unslop](https://github.com/heydamir/unslop)（CC BY 4.0）。适配与实施：潘涛 Studio。
