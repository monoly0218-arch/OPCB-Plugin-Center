# 修复与依据

| 位置 | 问题与修复 |
| --- | --- |
| 日期和图标 | Buzz 默认按钮含 8px/12px 内边距，挤偏小日期按钮。组件内显式控制间距和居中；数字启用等宽数字；图标不收缩，按钮文字与图标分别布局。 |
