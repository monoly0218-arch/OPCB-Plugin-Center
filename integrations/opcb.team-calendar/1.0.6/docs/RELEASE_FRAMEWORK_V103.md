# 本轮交付

在已有 1.0.2 上补齐开发框架，不新增复杂排期规则。默认工作区首次无示例任务，地址为 <http://127.0.0.1:4177>；原示例仍在端口 4176、原数据库中。两者独立，未迁移或清理旧数据。

1. 统一工作区／示例模式和连接配置，HTTP、命令连接器、变更订阅、Buzz 工具和 MCP 读取同一模式的配置；插件明确固定连接路径。
2. 空白页直接进入成员／项目设置或新建安排；显示实际连接状态，避免让本机连接被误解为跨设备共享。
3. 补架构、数据身份约定、接入边界、启动入口与 MCP 配置示例。
4. 构建只使用本工程依赖和 package-lock.json，不依赖其他本机项目的 node_modules。

- Ego Browser 在独立验收库实测：设置项目 → 创建第一项安排 → 引导消失 → 月历显示同一任务。连接器读取到 1 项任务、revision 2。用户工作区未填入验收任务。
- 检查浅色、深色与 390px 页面。窄屏 document 宽度为 390px，首次使用按钮均为 44px 高，日历网格在内部滚动。截图在交付包的截图目录。
