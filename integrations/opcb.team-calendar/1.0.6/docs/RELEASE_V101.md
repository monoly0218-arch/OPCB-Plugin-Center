# 团队日历 1.0.1

本机预览：<http://127.0.0.1:4176>。示例数据，不是实际团队任务或已发出的会议邀请。

## 本次完成

1. 新增团队月历：成员为行，真实月内日期为列。合并同一任务连续日期，间断日期保留断开；并行任务分行，项目和成员筛选共用原任务身份。保留原月网格。
2. 统一 Buzz 语义表面、文字、边框、选中和中性色主按钮；项目颜色仅作为分类标记。独立预览提供对应的浅色和深色回退值，插件内优先继承宿主颜色。
3. 点击任务先看速览卡，再进入完整编辑。Esc 关闭速览并恢复焦点；移动端速览贴近底部。表单内容和固定保存区分开，避免按钮挡住字段。
4. 会议支持日期、同日开始/结束、地点、线上方式与已有链接、负责人、参会成员、提前准备/进会时间和开始前提醒。会议出现在负责人及参会成员行，共用同一任务 ID。
5. 本机页面提醒及可选浏览器通知入口。提醒默认关闭，开启后覆盖当前页面全部会议；不会自动进入会议。系统通知需用户明确通过浏览器授权。

## 接入边界

腾讯会议自动创建尚未接入，本轮运行时没有可调用的腾讯会议工具。界面保留未连接状态和禁用按钮；已有 HTTPS 链接可保存并手动进入。不自动创建外部会议、不发送邀请。

提醒每 15 秒检查，触发窗口为 60 秒；页面需要打开且获得运行时间，浏览器后台暂停或设备休眠会影响触发。关闭页面后的后台调度、Buzz 推送、短信提醒尚未接通。系统通知有入口，未实测操作系统通知投递。

服务仍绑定本机回环地址。现有任务中心写回、团队跨设备部署、Buzz 原生插件安装验收仍未完成。新版交付不包含运行数据库、连接凭据或原任务记录；首次运行在独立运行目录生成示例数据。
