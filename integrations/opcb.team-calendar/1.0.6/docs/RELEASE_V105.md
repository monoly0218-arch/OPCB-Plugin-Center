# 设计原则

同一操作保留一个主入口；日期、时间粒度、项目、成员分别控制，不互相重置。依据：Moo 在当前设计团队日历会话确认“很多东西的功能点不能重复”（消息 cc332900c14dec5ba5fd2bf801ff6a93b11ae309608e422049cbda823338e78d）。

# 本次变化

| 功能 | 唯一主入口 |
| --- | --- |
| 日／周／月 | 日历右上角；移除左侧团队周历、团队月历、我的今日安排导航 |
| 新建安排 | 右上角；移除空白引导、周历每格、每日成员行中的重复添加按钮 |
| 成员与项目管理 | 左侧“管理成员与项目”；空白页只提示如何开始 |
| 只看我 | 成员筛选区；保留当前日期和视图，“今天”单独定位日期 |
| 本机会议提醒开关 | 顶部时钟；速览保留状态与系统通知授权，不重复开启按钮 |

保留周计划批量导入，以及月视图中的按日期／按成员布局。这些功能分别承担批量录入和月历呈现，不与新建单项安排、时间粒度切换重复。日期网格点击仍可进入当天详情；左侧小月历用于直接选择日期，主日期箭头用于按当前日／周／月前后翻页。

本机框架的“只看我”沿用原有 Moo 成员 ID 映射，仅在该成员存在时出现；尚未引入跨设备账户映射。
