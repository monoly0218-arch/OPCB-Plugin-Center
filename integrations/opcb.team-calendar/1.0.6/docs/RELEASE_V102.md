# 团队日历 1.0.2

本机预览：<http://127.0.0.1:4176>。代码与交付包已验证；视觉方向等待 Moo 评审，不记录为已获认可。

## 改动

1. 白色侧栏与内容区，浅色项目卡片，减轻灰色大面积铺底；日期、任务标题、项目色与选中态加强层次。
2. 侧栏跳转日期默认收起，顶部统一日／周／月，待安排缩为紧凑条。
3. 月历默认按日期显示负责人、时间与任务标题；超出两项时提供进入当日安排的按钮。
4. 按成员排期在固定左列显示完整任务名称，右侧显示准确日期区间，保留跨天、间断日期及任务唯一身份。
5. 速览按实际高度校正位置，保留键盘关闭和焦点恢复；会议时间、链接与提醒设置继续使用原数据。

## 验证

- 完整包 `npm test`：22 项通过，输出见 `TEST_RESULTS_V102.txt`。基线 HEAD 为 `a192a900fc66c41f1d0b264d7017aa02ae363800`，结果对应未提交工作树和交付 SHA256 清单，并非基线提交本身。
- Ego Browser 实测：周／月切换；月历日期、成员布局；完整任务名称无横向截断；项目筛选同时移除对应标题与排期条；月份切换显示 30／31 天；空月份仍保留成员。
- 从完整任务名称打开速览、Esc 关闭后恢复原任务焦点。会议编辑仍读取 2026-11-18、17:00–18:00 等原保存值。
- 会议速览底边校正后留在窗口内，底部操作可见；编辑内容滚动与固定保存区分别检查。
- 浅色、深色及 390px 窄屏检查。窄屏 document 宽度为 390px，宽月历在内部容器滚动。系统减少动态效果模式作为检查条件之一。
- 本次为 UI 调整，没有新增外部会议创建、通知投递或跨设备同步的验收结果。
