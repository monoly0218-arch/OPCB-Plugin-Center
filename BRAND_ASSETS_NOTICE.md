# Brand artwork

Brand marks identify the corresponding integrations. They are separate from the Microsoft Fluent Emoji MIT license and the plugin source license; their respective owners retain rights. No endorsement is implied.

- Muse character: exact public landing-page poster, https://muse.ai/images/landing/brand/hatch-avatar-134.webp (https://muse.ai), retrieved 2026-11-14. Meta character artwork.
- Grok Bot: icon exported with macOS sips from the installed Grok Bot 0.79.3 app, bundle identifier `com.anysphere.sand`, `Contents/Resources/icon.icns`. This is the app's round two-eye character, not the xAI Grok logo.
- Higgsfield: exact public website icon, https://higgsfield.ai/icon.png (https://higgsfield.ai), retrieved 2026-11-14.

All three resources are embedded locally. No user account images, credentials or personal avatar data are included. File hashes and source metadata are recorded in `src/plugin-center/assets/BRAND_ICONS.json` in the source repository.
