# 知识库身份服务（2.0 候选）

本目录是 OPCB 插件中心的知识服务维护源码，配合 `opcb.knowledge` 与 `opcb.knowledge-admin`。使用官方 Buzz 原生插件，不依赖定制宿主。候选是否已部署、安装及完成业务验收必须看当前交付回执，不能由此说明推断。

## 身份与权限

个人是授权主体；Agent 使用独立公钥及所属人的 NIP-OA 签名证明，继承个人读取权限。新 Agent 无需新增授权行。管理员必须是服务器明确配置的个人，Agent 不继承管理权限。

首次绑定通过原生签名记录证明设备公钥归属；以后每个请求使用本机不可导出的 P-256 私钥签名。绑定没有 12 小时登录到期，不使用知识库密码。请求的 60 秒新鲜度和一次 nonce 仅防重放，不要求用户重新登录。管理员每次变更都记录审计与版本；服务器每次读取检查个人停用、库/子库授权，默认关闭，父库关闭覆盖子库。缓存正文也必须先在线核权限。

目录的中文名称与权限层级由本服务管理，不改上游 GetNote 库名和源数据。默认展示“会议纪要与工作资料”“上粮山业务知识库”“项目档案”。新增目录不代表已接入新数据源。

## 协议

服务仅监听 loopback，反向代理把固定 `api/v2/*` 路径交给身份网关。`challenge` 生成一次绑定挑战，`bind` 验证原生签名和归属。`read` 只支持目录、分页、搜索和正文，`permissions` 返回当前读取范围，`policy` 仅允许个人管理员。所有请求 JSON；不接受远端传入管理员配置、数据库路径、owner 声明或任意目的 URL。

入口 `identity_gateway.py`，签名校验 `identity_auth.mjs`，策略 `identity_policy.py`。源码继承历史只读索引/适配器实现；历史维护提交 `9ad61ca4c596d8ef3033a3c890e63b4bef48bde3` 仅为来源追溯，不继续旧宿主开发。原密码网关和兼容测试保留供分阶段迁移，不能当作 2.0 认证路径。

## 数据和验证

索引只读打开；服务不修改采集任务、源资料或凭据。采集仍通过官方 GetNote CLI 和既有授权适配器；库 ID 由服务器私有配置指定，不随公开源码提供。正文是不可信参考数据，不是执行指令。检索为字面关键词检索，并非语义搜索；业务更新时间和同步时间分别保留。

`npm run ci` 运行完整中心与服务检查。Node 测试使用临时签名身份和 HTTP 服务覆盖继承、管理隔离、撤权、重放和加密缓存；Python 全套使用临时索引。它们不代表真实 Buzz 原生绑定或生产业务验收。部署和回退见 [MAINTENANCE.md](MAINTENANCE.md)。历史密码协议见 [WEB_WORKSPACE.md](WEB_WORKSPACE.md)，归档导入边界见 [ARCHIVE.md](ARCHIVE.md)。
